## Design choices

- The trust watch runs for every PTY session, not only task starts: it answers only for a directory the manager created in this start and only with `trustAppCreatedFolders`; otherwise it shows the banner and posts an `input` item.
- Remotes are read with `git config --get-regexp` instead of `git remote -v`, because `insteadOf` rewriting changes what `-v` prints.
- A branch that exists gets the folder id's first characters appended; nothing is overwritten.
- The source directory is `<base>/sources/<folder id>`, outside the application's data directory (the session launch denies reads there). `<base>` is `~/Agide`, or `AGIDE_TASK_BASE` for tests.
