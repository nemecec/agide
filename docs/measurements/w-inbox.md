## Decisions and deviations

- Session summaries live in the table `session_summaries` of the inbox module, not in a session migration, so the session module stays with w-provider. Tree migration 2 adds `description`, `description_updated_at` and `is_project` as in 0021.
- `inbox_asks`, `inbox_views` and `inbox_policies` are not created; their features wait (0021 section 12).
- `inbox_post` accepts only http and https URLs; the item link anchor schema does too.
- An agent resolves only items it posted, with `superseded` or `dismissed`. An agent keeps at most 20 reminders in its folder.
- The pane renders alone with `#pane=agide/inbox` in the URL (`main.tsx`), because no preset layout holds the inbox pane yet. The window blocks `will-navigate`, which also blocks `location.reload()` from page code; tests use `page.reload()`.
- Both this module and w-profiles may set the dock badge. Remove one when the profile module takes it over.
