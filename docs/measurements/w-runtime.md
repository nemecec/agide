## Built

The first slice of the stream-json agent runtime in `app/src/core/swarm/runtime`:

- `ndjson.ts`: tolerant line reader (partial lines, split multi-byte characters, CRLF, lines over 4 MiB dropped, bad lines reported and skipped).
- `normalize.ts`: stream-json message to `RuntimeEvent` (init, assistant usage, `can_use_tool` with the raw request, cancel, result, rate limit).
- `StreamChannel.ts`: stdin and stdout of one process, control requests with a timeout, `control_response` matching.
- `streamLaunch.ts`: the launch contribution (stream-json flags, model, effort, budget, turns, tools, directories, deny rules, subagent model variables).
- `StreamAgentRuntime.ts`: `AgentRuntime` and `StreamSpawner`; launch and resume through the session service, per-turn message queue, approvals, interrupt, steering, end, stop (interrupt, close stdin, SIGTERM, SIGKILL, process group), exit reporting, one live process per session.
- `processCommand` in the local, srt, container (`docker run -i`) and fake providers; `tty` option in `dockerArgs.ts`.
- `HookItemMapper` skips `PermissionRequest` and the `permission_prompt` notification for stream-json sessions.
- Fixtures: `fake-claude-stream.mjs` extended (set_permission_mode, noise, stubborn and stdin-ignoring modes, a child in the process group, the allowed input in the tool result), `fake-claude-script.mjs` (scripted stdout), `streamHarness.ts`.
- The `stream-json runtime` contract suite runs unskipped.
- Mutation entries `runtime:` in `scripts/mutation-checks.mjs`.
- `scripts/e2e-real-swarm-runtime.mjs` (real Haiku, outside the default tests).

## Contract notes

- `TurnResult` carries the cumulative cost but not `modelUsage` per model; the manager's ledger by model would need that field.
- `launch` returns after the first stdout line (or an early exit), so a CLI that rejects a session id fails the launch with `spawn`; a resume of an unknown conversation fails with `not_found`. A failed launch emits no events.
- Control requests of a kind the app does not handle are answered with an error response.
- `set_permission_mode` is passed through `control` and verified on the fake; the manager does not send it (0037).
